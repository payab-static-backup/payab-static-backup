# Payab.ir Static Backup

بک‌آپ استاتیک خودکار از سایت [payab.ir](https://payab.ir) برای استفاده در زمان قطعی یا اختلال دسترسی به هاست اصلی.

## نحوه کار

1. هر شنبه ساعت ۰۱:۳۰ به وقت ایران، GitHub Actions به‌صورت خودکار اجرا می‌شود
2. لیست تمام صفحات از سایت‌مپ‌های XML سایت استخراج می‌شود
3. با استفاده از `wget`، تمام صفحات به‌همراه فایل‌های CSS/JS/تصاویر دانلود می‌شوند
4. قبل از ذخیره نهایی، سلامت بک‌آپ با `scripts/verify.sh` بررسی می‌شود
5. در صورت موفقیت، نتیجه در پوشه `backup/` ذخیره و به این ریپازیتوری push می‌شود
6. Cloudflare Pages به‌صورت خودکار نسخه جدید را در آدرس `static.payab.ir` منتشر می‌کند
